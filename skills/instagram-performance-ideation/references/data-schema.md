# Data schema

## `posts.json`

An array produced by `fetch`:

```json
[
  {
    "id": "MEDIA_ID",
    "caption": "caption",
    "media_type": "IMAGE",
    "media_product_type": "FEED",
    "media_url": "temporary CDN URL",
    "thumbnail_url": "temporary CDN URL",
    "permalink": "https://www.instagram.com/p/.../",
    "timestamp": "2025-01-01T00:00:00+0000",
    "like_count": 0,
    "comments_count": 0,
    "metrics": {
      "reach": 0,
      "shares": 0,
      "saved": 0,
      "follows": 0
    },
    "metrics_error": ""
  }
]
```

Metric availability differs by media type, account, API version, and permissions. Missing metrics remain absent or zero; failures are recorded in `metrics_error`.

## `labels.json`

An object keyed by media ID. Unknown extra fields are preserved by the user's file but ignored by ranking.

```json
{
  "MEDIA_ID": {
    "content_text": "text or faithful creative summary",
    "topic": "topic",
    "format": "format",
    "situation": "audience situation",
    "mechanism": "why the construction works",
    "send_to": "sender → receiver",
    "exclude": false
  }
}
```

`exclude: true` prevents a post from becoming either a source candidate or a recent reference.

## `used.json`

A JSON array of media IDs already consumed in the current source rotation:

```json
["MEDIA_ID_1", "MEDIA_ID_2"]
```

## `candidates.json`

Generated by `rank`:

- `objective`: metric names and weights;
- `candidates`: older ranked and deduplicated sources;
- `recent_reference`: recent posts sorted by timestamp;
- `rotation_reset`: whether used IDs were ignored because the cycle ran out;
- `stats`: filtering and pool counts.
